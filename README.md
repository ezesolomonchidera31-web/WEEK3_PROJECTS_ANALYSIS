# WEEK3_PROJECTS_ANALYSIS_UNDER_ANALYSTLABAFRICA
This week, I completed two SQL projects using industry-standard sample databases to strengthen my data querying, analysis, and problem solving skills.


# PROJECTS INTRODUCTION OF THE TWO PROJECTS

## CHINOOK PROJECT
The first project was built using the Chinook Database, a digital music store database containing information on customers, invoices, artists, albums, tracks, playlists, employees, and genres. Through this project, I practiced writing SQL queries involving multiple table joins, filtering, aggregation, grouping, subqueries, and business-oriented analysis such as identifying top-selling artists, customer purchasing behavior, and revenue trends. The Chinook database is designed as a realistic relational database for learning and testing SQL concepts.

## SALES DATASET
The second project focused on a Sales Dataset/ Sample Sales Data, where I analyzed sales performance, customer transactions, product demand, and revenue metrics. This project strengthened my ability to generate meaningful business insights using SQL by applying aggregate functions, sorting, ranking, Common Table Expressions (CTEs), window functions, and data summarization techniques. I explored sales trends, identified high-performing products, and answered practical business questions that support data-driven decision-making.
